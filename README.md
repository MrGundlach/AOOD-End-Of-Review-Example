# Project Demos
## Project 1 - Array-versus-ArrayList-AOOD
Lab: Array versus ArrayList Performance and Use-Cases

### Objective
Understand the differences between Java built-in fixed-size **Arrays** and dynamic **ArrayLists** regarding:
1. Syntax & Declaration
2. Elements Insertion & resizing
3. Accessing & Modifying data
4. Performance differences (Fixed capacity vs Dynamic resizing)
